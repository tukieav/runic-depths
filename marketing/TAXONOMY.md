# Runic Depths v2 — proposed taxonomy

These are editorial suggestions based on the current game, not verified CrazyGames tag identifiers or approved portal categories. Confirm available choices in the submission interface before publishing.

| Field | Proposed description | Basis in the game |
| --- | --- | --- |
| Main genre | Action RPG | Real-time attacks, dodging, class abilities, equipment, and character progression |
| Secondary genre | Dungeon crawler / adventure | A twelve-depth expedition with quests, collectible memories, and a branching campaign |
| Visual presentation | Isometric 3D | An angled orthographic camera over a WebGL-rendered 3D world |
| Setting | Fantasy / magic | An original city of memories, runic powers, and supernatural guardians |
| Discovery themes | RPG, monsters, bosses, loot, exploration | Five classes, 24 regular enemy archetypes, six bosses, equipment, and procedural maps |
| Play modes | Single player | One locally controlled hero and a saved campaign |
| Input | Keyboard and mouse / touch | Desktop controls plus joystick and six mobile action buttons |
| Languages | English / Polish | Both UI and campaign content are localized |
| Intended audience | 12+ | Stylized fantasy conflict and themes of loss, without gore; no formal rating claimed |

Do not reuse the old `Turn-Based`, `Pixel`, or `2D` descriptors. The current game uses continuous action combat and 3D geometry. Procedural maps alone do not make it a permadeath roguelike: the campaign supports reviving and resuming saved progress, so “roguelike” is not proposed as a primary description.

The former portfolio mapping and historical tag URLs are not evidence for the current release. Use [SUBMISSION.md](SUBMISSION.md) for the current description and release scope.
